<original_problem_statement>
Build a complete mobile app called **Reassura**, a private, invite-only peace-of-mind and family safety app.

**PRODUCT REQUIREMENTS:**
- **Tech Stack**: React Native (Expo, TypeScript) frontend, FastAPI/MongoDB backend.
- **Core Concept**: Users voluntarily share their status (e.g., Home, Travelling) with trusted circles. It is built on trust and privacy, not surveillance.
- **Key Screens**:
    1.  **Home**: Peace Score, swipeable Circle switcher, Stories row for user statuses, a feed of Latest Footprints, and a floating SOS button.
    2.  **Map**: A 3D-styled dark map showing member locations (neighborhood level only) with custom teardrop pins indicating status.
    3.  **Circles**: A visual representation of user-created circles with pulsating animations and orbiting member emojis.
    4.  **Travel**: A swipeable, multi-page view for tracking live flights, viewing a night sky map of the journey, and managing a travel profile.
    5.  **Profile**: User profile management, avatar selection, and privacy settings.
    6.  **Update Status**: A simple screen for users to update their current status and add an optional message.
- **Critical UX**: All multi-page screens and carousels MUST support native swipe gestures. The aesthetic is warm, dark, organic.
- **Life360-inspired features (Privacy-first)**: Place detection, battery level sharing, driving mode, check-in requests, safety windows, etc., all to be implemented as opt-in features.
- **New Feature Request (In Progress)**:
    1.  Sidebar Drawer Navigation
    2.  Enhanced Map Pins & Animations
    3.  Simulated Real-Time Updates
    4.  Full Authentication/Onboarding Flow
    5.  Profile Picture Upload capability
    6.  Saved Places on Map
    7.  Guided Demo Mode
